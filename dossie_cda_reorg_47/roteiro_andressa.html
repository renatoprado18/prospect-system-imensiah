Passo A — e-CAC / Receita: Relatório de Situação Fiscal (o principal)

Esse relatório traz, num PDF só, as pendências da Receita + as inscrições em Dívida Ativa da PGFN de cada CNPJ.

  1. Acesse cav.receita.fazenda.gov.br → Entrar com gov.br → seu login (procuração eletrônica já liberada).
  2. Se precisar, use Alterar perfil de acesso (canto superior) para entrar como cada empresa.
  3. Menu Certidões e Situação Fiscal → Consulta Pendências - Situação Fiscal.
  4. Gere/baixe o relatório em PDF.
  5. Repita para cada um dos 7 CNPJs + o CPF do Renato.
  6. Salve como: SitFiscal_<Empresa>.pdf

Obs.: no fim de semana esse relatório estava com erro (portal novo). Se der erro na 2ª também, siga para o Passo B e avise o Renato.

Passo B — Regularize / PGFN: extrato de inscrições em Dívida Ativa (detalhe CDA-a-CDA)

  1. Acesse regularize.pgfn.gov.br → Entrar com gov.br (Pessoa Jurídica / Física conforme o caso).
  2. Vá em Consulta de Inscrições (ou “Emitir relatório/extrato de débitos inscritos”).
  3. Para cada CNPJ + o CPF, baixe o extrato com a lista de inscrições.
  4. Salve como: Regularize_<Empresa>.pdf

O que anotar por CDA (planilha simples, uma aba por empresa)

Nº inscrição/CDA · Tributo (Simples / Previdenciário / etc.) · Valor · Data de inscrição · Situação (ajuizada / a ajuizar / parcelada / suspensa) · Nº do processo (se ajuizada).

Prioridade: Carambola (~R$2,12M, a maior — separar o Previdenciário dos demais), depois AB (~R$440k). Em Makerfest / Framboesa / Empreseira, o ponto é confirmar se estão parceladas ou já quitadas.

Entrega
